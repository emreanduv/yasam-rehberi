# Gezi Pasaportu

Gezdiğin ülkeler, şehirler ve seyahatler: dünya haritası, her ülkeye bir pasaport damgası, kıta ve yıl istatistikleri, yedek ve gezi kartı. iOS + Android (Capacitor), internetsiz, veri yalnız cihazda.

- `npm run serve` → http://localhost:8791
- `npm run veri` → harita/ülke/şehir verilerini yeniden derler
- `python3 test/ekranlar.py` → ekran testi

Kaynaklar: Natural Earth (kamu malı), GeoNames (CC BY 4.0), countries-list ve i18n-iso-countries (MIT).
